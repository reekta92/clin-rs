# Help View

## Overview

The help view provides a 3-pane layout: a left pane with a keybind table for the active scope, a right-top pane with the tab description and popup accordion, and a right-bottom pane with curated tips. Users can press `?` or `F1` from any view to open help.

**Source:** `src/ui/help.rs`, `src/ui/help_content.rs`, `src/events/help.rs`, `src/keybinds/help_meta.rs`

## Tabs

The help view has 8 tabs in order:

| # | Tab | Description |
|---|---|---|
| 1 | **Notes** | Browse, organize, and manage your notes and folders |
| 2 | **Editor** | Write and edit the selected note's title and body |
| 3 | **Graph** | Visualize your notes as a force-directed graph |
| 4 | **Draw** | Freehand strokes, shapes, and text on a drawing canvas |
| 5 | **Canvas** | Infinite pinstar canvas for connecting notes and drawings |
| 6 | **Backup** | Git-backed vault backup dashboard |
| 7 | **Templates** | Reusable note templates with variable substitution |
| 8 | **About** | Application metadata, config paths, CLI reference |

Digits `1`–`7` jump directly to the first seven tabs; the eighth tab (About) is reached via `Tab`/`Right`.

## Keybind Index

The keybind table is generated by `generate_scope_help` (`src/ui/help.rs:397-443`). It buckets action-enum variants by group via `help_meta`, renders heading + item rows, and fetches keybinds live via `keybinds.{scope}_keys_dispatch(action)`. Templates and About tabs use static rows instead of generated ones.

## Tips Pane

The tips pane displays `HelpSuggestion` entries (`src/ui/help_content.rs:32-57`) — a curated pool per tab with optional `TipRequirement` (Counts, Sequences, Preset, or None). When the active config fails a requirement, `caveat_if_unsatisfied` renders a caveat note alongside the tip. Tip bodies use `{scope:Action}` tokens resolved by `resolve_tip_key` (`src/ui/help.rs:1319-1447`).

## Popup Accordion

The info pane (upper-right) shows the active tab's description plus a popup-help accordion cycled with `n`/`N`. See `draw_help_info_pane` at `src/ui/help.rs:1066-1136`.

## Configuration

| Keybind | Scope | Description |
|---|---|---|
| `keybinds.show` | Global | Open help view |
| `keybinds.next_tab` | `[help]` | Next tab |
| `keybinds.prev_tab` | `[help]` | Previous tab |
| `keybinds.scroll_up` | `[help]` | Scroll up |
| `keybinds.scroll_down` | `[help]` | Scroll down |
| `keybinds.search` | `[help]` | Search help content |

The digit-jump shortcuts (`1`–`9`) are fixed and not configurable in `keybinds.toml`.

# Help View

## Overview

The help view provides a 3-pane layout: a left pane with a keybind table for the active scope, a right-top pane with the tab description and popup accordion, and a right-bottom pane with curated tips. `F1` opens contextual help outside Setup; `?` is a navigation-view help binding, not a global shortcut inside text inputs. Closing Help restores the previous view.

**Source:** `src/ui/help.rs`, `src/ui/help_content.rs`, `src/events/help.rs`, `src/keybinds/help_meta.rs`

## Tabs

The help view has up to 8 tabs in order. Disabled-feature tabs are omitted:

| # | Tab | Description |
|---|---|---|
| 1 | **Notes** | Browse, organize, and manage your notes and folders |
| 2 | **Editor** | Write and edit the selected note's title and body |
| 3 | **Graph** | Visualize your notes as a force-directed graph |
| 4 | **Draw** | Freehand strokes, shapes, and text on a drawing canvas |
| 5 | **Canvas** | Infinite pinstar canvas for connecting notes and drawings |
| 6 | **Backup** | Git-backed vault backup dashboard |
| 7 | **Templates** | Reusable note templates with variable substitution |
| 8 | **About** | Application metadata, config paths, CLI reference |

Digits `1`–`8` jump to visible tabs by position; `Tab`/`Right` and `Shift+Tab`/`Left` cycle them. If a custom help binding matches a digit, it takes precedence.

## Keybind Index

The keybind table is generated by `generate_scope_help` (`src/ui/help.rs`). It buckets action-enum variants by group via `help_meta`, renders heading + item rows, and fetches keybinds live through scope-specific key display methods. Templates and About tabs use static rows; their paths come from the active `Storage`.

## Tips Pane

The tips pane displays `HelpSuggestion` entries (`src/ui/help_content.rs:32-57`) — a curated pool per tab with optional `TipRequirement` (Counts, Sequences, Preset, or None). When the active config fails a requirement, `caveat_if_unsatisfied` renders a caveat note alongside the tip. Tip bodies use `{scope:Action}` tokens resolved by `resolve_tip_key` (`src/ui/help.rs:1319-1447`).

## Popup Accordion

The info pane (upper-right) shows the active tab's description plus a popup-help accordion cycled with `n`/`N`. See `draw_help_info_pane` at `src/ui/help.rs:1066-1136`.

## Configuration

| Keybind | Scope | Description |
|---|---|---|
| `F1` | Global | Open contextual help (except Setup) |
| `close` | `[help]` | Close help and restore previous view |
| `next_tab` | `[help]` | Next tab |
| `prev_tab` | `[help]` | Previous tab |
| `scroll_up` | `[help]` | Previous page |
| `scroll_down` | `[help]` | Next page |
| `search` | `[help]` | Search help content |
| `reroll` | `[help]` | Refresh suggested tips |

Digit jumps (`1`–`8`) and popup accordion keys (`n`/`N`) are fallback handlers, not separate configurable actions. Bare `q`/`Esc` always close Help after any active search popup is handled.
